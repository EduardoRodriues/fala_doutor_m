# 🏥 Sistema de Gestão Administrativa de Clínica Médica

Aplicação web moderna para gestão administrativa de clínicas médicas, desenvolvida com arquitetura de **microserviços** e tecnologias de ponta, garantindo **escalabilidade**, **modularidade** e **alta manutenibilidade**.

---

## 🚀 Tecnologias Utilizadas

### **Backend**
- **Node.js** + **Express**
- Banco de dados **PostgreSQL**
- Arquitetura baseada em **microserviços**
- CRUD completo para:
  - Médicos
  - Pacientes
  - Planos de saúde
  - Outros módulos administrativos
- API **RESTful** para comunicação com o frontend
- Testes e validações via **Postman**

### **Frontend**
- **React** (SPA)
- Interface **responsiva** e **intuitiva**
- Experiência do usuário otimizada (UX/UI)

### **Diferenciais**
- **Chatbot Inteligente** com **Retrieval-Augmented Generation (RAG)**
  - Respostas contextuais e precisas sobre os próprios serviços do sistema
  - Auxílio em tempo real para usuários e administradores

---


---

## ⚙️ Funcionalidades

- 📋 **Cadastro, edição, listagem e exclusão** de médicos, pacientes, planos de saúde, etc.
- 🔗 Integração entre **frontend** e **backend** via **API RESTful**
- 🤖 **Chatbot com RAG** para suporte contextual sobre os serviços
- 📱 Interface **responsiva** para desktop e mobile
- 🛠 Arquitetura de **microserviços** para fácil manutenção e expansão

---

## 🖥️ Pré-requisitos

- **Node.js** >= 18.x
- **PostgreSQL** >= 14.x
- **npm** ou **yarn**
